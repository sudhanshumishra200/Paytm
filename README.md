# 💸 E-Wallet Web App

A full-stack web application that allows users to register, log in, and securely perform peer-to-peer transactions. The app features a responsive user interface, secure authentication, and real-time transaction handling using modern web technologies.

## 🚀 Features

- 🔐 User Authentication (Sign Up / Sign In) using JWT
- 💳 Peer-to-Peer Money Transfers
- 📜 Transaction History and Wallet Balance Display *(optional if implemented)*
- ⚙️ Error Handling and Form Validation
- 🌐 Fully Responsive Design

## 🛠️ Tech Stack

### Frontend
- **React** – for building the user interface
- **Tailwind CSS** – for styling and responsive design
- **Axios** – for handling API requests

### Backend
- **Node.js & Express.js** – for server-side logic and API routes
- **MongoDB & Mongoose** – for database and data modeling
- **JWT (JSON Web Token)** – for secure authentication
- **dotenv** – for environment variable management

### Deployment
- **Frontend** – Deployed on [Vercel](https://vercel.com/)
- **Backend** – Deployed on [Render](https://render.com/)
- **Database** – Hosted on [MongoDB Atlas](https://www.mongodb.com/atlas)

## 🧑‍💻 Getting Started

### Prerequisites

Ensure you have the following installed on your local machine:

- Node.js (v14 or above)
- npm or yarn
- Mongodb Atlas account or local Mongodb

### Clone the Repository

```
git clone https://github.com/yourusername/e-wallet-app.git
cd e-wallet-app
```
